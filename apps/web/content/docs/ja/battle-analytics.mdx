## 概要

勝率分析（`/battle-analytics`）は、[対戦記録](/docs/battle-record) に蓄積された試合データをもとに、勝率や選出傾向を自動集計・可視化する分析ツールです。

単なる総合成績だけでなく、「どのポケモンを選出した時に勝てているか」「どのチーム構成が最も機能しているか」「環境のどのポケモンに勝率を落としているか」をタブ切り替えで深く掘り下げて確認できます。

---

## 3つの詳細分析タブ

画面上部のタブから、分析したい視点をワンクリックで切り替えることができます。

### 1. 使用ポケモン別分析（選出率・選出時勝率）

自チームの登録ポケモンごとに、以下の指標を集計・表示します。

| 指標                    | 説明                                     | 分析での着眼点                                                                                                               |
| :---------------------- | :--------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------- |
| **選出数 / 選出率 (%)** | 全試合中、そのポケモンを選出した割合     | チーム内の選出頻度。「構築の軸」として機能しているか、あるいは「選出率が極端に低く置物になっていないか」をチェックできます。 |
| **選出時勝率 (%)**      | そのポケモンを選出した試合における勝率   | 「選出したら勝てているキーマン」や、「選出率は高いが勝率を落としている原因」を定量的に特定できます。                         |
| **先発 / 後発内訳**     | 先発（初手）または後発として選出した割合 | 先発ペアとしての適性や、スイーパー（後発詰め）としての機能度合いを検証できます。                                             |

### 2. 使用パーティ別戦績

複数のチームを運用している場合、チーム（パーティ）ごとの成績を比較できます。

- **チーム別通算勝率・勝敗数**: どの構築が現在のランクマッチ環境に最も適合しているかを比較。
- **調整バージョンごとの成果**: [チームビルダー](/docs/team-builder) のリビジョンと照らし合わせ、調整前後の勝率推移を確認できます。

### 3. 相手ポケモン別勝率

相手のパーティに登場したポケモンごとに、対戦回数と勝率を集計します。

- **明確な苦手ポケモンの特定**: 「対戦回数は多いが勝率30%台にとどまっている」といった、現チームの弱点となるポケモンを客観的にあぶり出せます。
- **環境メタの把握**: 現在のシーズンで頻出している流行ポケモン（トップメタ）の遭遇頻度を把握できます。

## 絞り込みと活用サイクル

### シーズン・チームフィルタ

画面上部のセレクターから、集計対象の **シーズン** や **チーム** を絞り込むことができます。特定のチーム専用の戦績や、特定ルール期間のデータのみを抽出して分析可能です。

### チーム改善へのフィードバック

1. **分析**: 相手ポケモン別勝率で苦手な相手（例: トリル起動役）を特定する。
2. **考察**: [チームビルダー](/docs/team-builder) の「戦略ノート」を開き、苦手ポケモンへの立ち回りプランや選出パターンを再検討する。
3. **調整**: [ダメージ計算機](/docs/damage-calc) で耐性や確定数を再計算し、努力値や持ち物を微調整（リビジョン保存）。
4. **実戦**: 再び対戦を行い、選出時勝率が改善したかを検証する。
