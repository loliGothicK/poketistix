> ダッシュボードはデスクトップ環境でのみ利用可能です。

**「Dashboard」** では、ウィジェットを自由に配置してカスタム分析画面を作れます。
対戦記録と組み合わせた活用例は [実践ワークフローガイド](/docs/workflow-guide) を参照してください。

### ウィジェットの種類

| ウィジェット               | 説明                               |
| -------------------------- | ---------------------------------- |
| **勝率サマリー**           | 勝率を1つの数値で表示              |
| **結果別内訳**             | 勝・負・引分の内訳                 |
| **先発 / 後発 成績**       | 先発ポケモンごとの勝率             |
| **レート推移**             | 試合ごとのレート推移グラフ         |
| **最高レート**             | シーズン最高レート                 |
| **直近の試合**             | 直近10試合                         |
| **現在のストリーク**       | 現在の連勝 / 連敗ストリーク        |
| **先発相性表**             | 先発 vs 相手先発の勝率ヒートマップ |
| **勝敗要因ブレイクダウン** | 相手ポケモンの勝敗への影響度       |

### ウィジェットの追加

1. ダッシュボードを編集モードにする（「編集」ボタン）
2. **「ウィジェットを追加」** をクリック
3. ウィジェット種別を選択
4. データソース（シーズンまたは変数）を設定
5. Visualize タブでグラフ種別を選択

### 変数

変数を使うと、ドロップダウンでシーズンを切り替えてウィジェット全体を更新できます。
複数シーズンの比較に便利です。

### Transformer

Transformer を使うと、SQLクエリの結果をカスタム変換してグラフに渡すことができます。

| Transformer          | 説明                     |
| -------------------- | ------------------------ |
| なし（そのまま渡す） | そのまま渡す             |
| 勝率計算             | 勝率を計算               |
| ストリーク計算       | 連勝ストリークを計算     |
| 先発勝率             | 先発ごとの勝率           |
| レート変動           | レート変動を追加         |
| 先発相性ピボット     | 先発相性ピボットテーブル |
| 勝敗要因分析         | 勝敗要因分析             |

## ダッシュボードの保存と共有

ダッシュボードはクラウドに保存されます（ログイン必須）。
複数のダッシュボードを作成し、デフォルトを設定することもできます。
