## 概要

対戦記録は、ポケモン対戦の結果を試合ごとに素早く記録・管理するためのツールです。
シーズン単位で管理でき、チームビルダーで作成したパーティの選出、相手パーティや選出、対戦メモなどを一元管理できます。
一連の流れは [実践ワークフローガイド](/docs/workflow-guide) でも詳しく解説しています。

## シーズンの作成

対戦記録を開始するには、まず **シーズン** を作成する必要があります。

1. サイドバーの **「新規シーズン」** をクリック
2. シーズン名・フォーマット（シングル / ダブル）・レギュレーション・期間を設定
3. 「保存」で作成完了

## 対戦の記録

シーズンを選択した状態で **「対戦を記録」** ボタンをクリックするか、キーボードの **`N`** キーを押すと記録ダイアログが開きます。

### 記録できる情報

| 項目         | 説明                                                               |
| ------------ | ------------------------------------------------------------------ |
| 勝敗         | 勝ち (`W`) / 負け (`L`) / 引き分け (`D`)                           |
| 自分のチーム | [チームビルダー](/docs/team-builder) で作成したチームを選択        |
| 自チーム選出 | 各ポケモンの役割（未選出 / 後発: 青 / 先発: 黄）をタップで切り替え |
| 相手チーム   | 相手のパーティ（最大6体）と相手選出（先発/後発）                   |
| 相手詳細情報 | 相手カードの鉛筆アイコンから持ち物・特性・技・メモを追記           |
| レート       | 対戦後レート（直前の試合からの増減を自動計算）                     |
| メモ         | 重要な立ち回り・脅威・敗因などを自由記述                           |
| タグ         | ギミック（トリル、おいかぜ、雨等）や役割の分類タグ                 |

### 選出の記録

チームパネルで各ポケモンをタップすると、選出状態を切り替えられます。
（`未選出` → `後発`（青） → `先発`（黄） → `未選出` ... の順にトグルします）
相手チームのポケモンも同様にタップすることで選出状況を記録できます。

### キーボードショートカット

| キー                           | 操作                                     |
| ------------------------------ | ---------------------------------------- |
| **`N`**                        | 対戦記録ダイアログを開く（一覧画面時）   |
| **`W`**                        | 結果を「勝ち (WIN)」に設定               |
| **`L`**                        | 結果を「負け (LOSS)」に設定              |
| **`D`**                        | 結果を「引き分け (DRAW)」に設定          |
| **`1`** 〜 **`6`**             | 自チームメンバーの選出をトグル           |
| **`A`**                        | 相手ポケモンを追加（検索ダイアログ）     |
| **`Alt + 1`** 〜 **`Alt + 6`** | 相手ポケモンの選出をトグル（空なら検索） |
| **`Alt + R`**                  | 相手チームのスロットを一括リセット       |
| **`Ctrl + S`** / **`Cmd + S`** | 記録を保存                               |
| **`Esc`**                      | ダイアログを閉じる                       |

## 対戦記録の一覧と分析への連携

- **サマリーバー**: 現在のレート、勝率、W/L/Dの内訳プログレスバーを上部に常時表示。
- **フィルタ**: 「すべて」「勝ち」「負け」「引き分け」で瞬時に絞り込み可能。
- **データ分析**: 画面上部の「勝率分析」から [勝率分析](/docs/battle-analytics) や [ダッシュボード](/docs/dashboard) へ遷移し、蓄積された記録から多角的な統計・相性分析を行えます。

## 記録の削除

各対戦記録の削除ボタンから削除できます。この操作は取り消せません。

## ログインとデータ同期

ログインしている場合、対戦記録はクラウドに保存されます。
複数デバイスからアクセスする場合は、ログインを推奨します。
