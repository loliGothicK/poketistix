## 概要

ダメージ計算機は、攻撃側・防御側のポケモン、技、フィールド状態を指定して、精密なダメージ範囲（実数値・HP割合）と KO 確率（確定数・乱数幅）を即座にシミュレーションするツールです。

ダブルバトル特有の全体技分散（0.75倍）や「てだすけ」「フレンドガード」などの複合サポート効果、Champions 独自の努力値配分（各ステータス上限32、合計66）に完全対応しています。

---

## マイBOXからの高速読み込み

攻撃側・防御側それぞれの入力欄上部にある **「BOXから読み込む」** ボタンをクリックすると、[マイBOX](/docs/my-box) に保存してある育成済みポケモンを直接呼び出すことができます。

- **ワンクリックで全ステータス反映**: 努力値配分・性格・持ち物・特性・覚えている4つの技が一括でセットされます。
- **効率的なダメージ検証**: 「BOXにいる耐久調整済みのポケモンが、相手の攻撃を耐えられるか？」「自分のエースのアタッカー配分で確定1発を取れるか？」といった実戦想定の計算を、数値を手入力する手間なく瞬時に実行できます。

---

## 基本的な計算手順

1. **攻撃側のポケモンを設定**: 名前検索（ひらがな・ローマ字対応）または「BOXから読み込む」で指定。
2. **技を選択**: 覚えている技一覧から選択（または全技一覧から検索）。
3. **防御側のポケモンを設定**: 対象ポケモン・努力値・持ち物を指定。
4. **結果の確認**: ダメージ範囲、HPバーの減少率、確定数/乱数割合がリアルタイムに計算されます。

---

## 攻撃側・防御側のパラメータ

各サイドで以下の設定を柔軟に調整できます。

| 項目           | 説明                                                                                    |
| :------------- | :-------------------------------------------------------------------------------------- |
| **ポケモン**   | 名前検索（漢字・ひらがな・`gabu` などのローマ字入力に対応）。メガシンカ切り替えも可能。 |
| **努力値**     | 各能力値 0〜32、合計 66 の範囲でスライダーまたは数値入力。                              |
| **個体値**     | 0〜31（最遅調整やイカサマ対策のこうげき0などに対応）。                                  |
| **性格**       | 上昇補正（+10%）および下降補正（-10%）の性格。                                          |
| **持ち物**     | こだわりアイテム、いのちのたま、オボンのみ、タイプ強化アイテムなど。                    |
| **特性**       | 計算に影響する攻撃側/防御側の特性（きもったま、ちからもち、マルチスケイル等）。         |
| **ランク補正** | 各能力の -6 〜 +6 段階の能力変化。                                                      |
| **状態異常**   | やけど（物理半減）、まひ、ねむりなど。                                                  |

## フィールド・サポート条件

ダブルバトルの戦況を左右する各種フィールド条件をワンタップで切り替えられます。

### 天候・フィールド

- **天候**: 晴れ（炎1.5倍/水半減）、雨（水1.5倍/炎半減）、雪（氷防御1.5倍）、砂嵐（岩特防1.5倍）。
- **フィールド**: グラス（草1.3倍/じしん等半減）、エレキ（電気1.3倍）、サイコ（エスパー1.3倍）、ミスト（ドラゴン半減）。

### 壁・ダメージ軽減

- **オーロラベール / リフレクター / ひかりのかべ**: ダブルバトルにおける軽減倍率を正確に計算。
- **フレンドガード**: 隣の味方が受けるダメージを 0.75 倍に軽減。

### 強化サポート

- **てだすけ**: 攻撃威力を 1.5 倍に強化。
- **じゅうでん / バッテリー / パワースポット** などの各種火力サポート特性・状態。

## 計算結果の見方

- **確定数 / 乱数表示**: 「確定1発 (100%)」「乱数1発 (68.8%)」「確定2発」など、対戦時の判断に直結する指標を表示します。
- **ダメージ実数値**: 16段階すべてのダメージ乱数値を一覧表示。
- **HP割合バー**: 防御側の残りHPの変動を視覚的なカラーバーで確認可能。
- **テキスト出力**: Showdown / 計算機標準フォーマットでの結果テキストをワンクリックでコピーできます。
