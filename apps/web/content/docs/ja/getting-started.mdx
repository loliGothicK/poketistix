Pokétistix は、ポケモン競技対戦（ランクマッチ等）をサポートするための統合ツールセットです。
チーム構築から対戦時のダメージ計算、そして対戦記録と分析まで、対戦におけるすべてのプロセスを1つのプラットフォームで完結させることを目的としています。

## ワークフローの全体像

Pokétistix では、以下のサイクルで対戦環境を構築・改善していきます。

1. **構築（チームビルダー / マイBOX）**
   - 新しいアイデアや調整したポケモンを **チームビルダー** でチームにまとめます。
   - 育成済みの個体は **マイBOX** に保存しておくことで、他のチームでも簡単に呼び出して再利用できます。
2. **検証（ダメージ計算）**
   - 構築したポケモンが環境のメジャーな相手に対してどの程度戦えるか、**ダメージ計算** で事前に計算・確認します。
   - ダメージ計算の結果をもとに、チームビルダーに戻って努力値や持ち物を微調整します。
3. **対戦・記録（対戦記録）**
   - 実際のランクマッチでの対戦結果を **対戦記録** に記録します。
   - 相手のパーティ、選出、勝敗、そして重要なメモを残すことで、対戦の振り返りが可能になります。
4. **分析・改善（勝率分析）**
   - 蓄積された記録から **勝率分析** で勝率や選出の傾向を分析します。
   - 苦手なポケモンや負けの要因を特定し、再び「構築」フェーズに戻ってチームを改善します。

## 主要機能

- **[実践ワークフローガイド](/docs/workflow-guide)**
  - チーム構築から対戦記録の入力、勝率分析・ダッシュボードでのデータ閲覧までの一連のサイクルを解説。
- **[チームビルダー](/docs/team-builder)**
  - ドラッグ＆ドロップによるチーム編成、詳細なステータス・努力値設定。
  - Pokepaste 形式でのインポート/エクスポート対応。
- **[マイBOX](/docs/my-box)**
  - 汎用性の高い育成済みポケモンをストックし、チーム構築を高速化。
- **[ダメージ計算](/docs/damage-calc)**
  - シングル・ダブル両対応のダメージ計算機。フィールドや天候、ランク補正を完全サポート。
- **[対戦記録](/docs/battle-record)**
  - 選出ポケモンや相手の構成、対戦メモをシーズンごとに一元管理。
- **[勝率分析](/docs/battle-analytics)**
  - ウィジェットを組み合わせて自分好みの分析ダッシュボードを作成可能。

## アカウント登録のメリット

Pokétistix はログイン不要（ゲスト状態）でも利用可能で、その場合はデータがブラウザのローカルストレージに保存されます。
しかし、アカウントを作成してログインすることで以下のメリットがあります。

- **クラウド同期**: チームや対戦記録がクラウドに安全に保存され、PCとスマートフォン間でデータを共有できます。
- **永続化**: ブラウザのキャッシュクリアによってデータが消失するリスクを防ぎます。
- **高度な分析**: ダッシュボードなど、一部の高度な機能が利用可能になります。

まずはサイドバーから各ツールの詳細マニュアルを確認し、実際に使ってみてください！
