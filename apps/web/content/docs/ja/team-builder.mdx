## 概要

チームビルダーは、Pokémon Champions のダブルバトル向けに競技対戦チームを構築・管理するためのツールです。
最大6体のポケモンを登録し、持ち物・特性・技・努力値（各ステータス上限32、合計上限66）を細かくカスタマイズできます。

さらに、過去の調整を安全に振り返り復元できる **「リビジョン履歴」** や、構築意図・選出プランを詳細にまとめられる **「戦略ノート」** 、育成済みポケモンを即座に呼び出せる **「BOX連携」** などを備えています。
作成したチームは、[対戦記録](/docs/battle-record) や [勝率分析](/docs/battle-analytics) で直接呼び出して選出管理・パフォーマンス追跡に利用できます。

## ポケモンの追加と検索

チームの空きスロットをクリックすると、ポケモン選択ダイアログが開きます。

### 柔軟な検索機能

- **名前・部分一致検索**: ポケモン名を入力して絞り込み（例: `ガブリアス`）。
- **ひらがな・ローマ字入力対応**: 日本語入力環境において、ひらがな（`がぶりあす`）だけでなくローマ字（`gabu`、`rizadon`、`sa-fugo-` など）での直感的な検索に対応しています。
- **タイプフィルタ**: `@type:ドラゴン` や `@type:はがね` のようにタイプ条件での絞り込みが可能です。
- **自動状態リセット**: スロットを切り替えた際や再検索時に前回のキーワードやチップが残らないため、ストレスなく次のポケモンを選択できます。

### マイBOXからの直接読み込み

画面上部のタブから **「BOX」** を選ぶと、あらかじめ [マイBOX](/docs/my-box) に保存してある育成済みポケモンを一覧表示できます。

- 努力値配分・持ち物・覚えている技を確認しながら直接スロットへ追加できます。
- 空スロットや各スロットのヘッダーにある **「BOXから読み込む」** アイコンからも、ワンクリックで呼び出し可能です。

## ポケモンの詳細設定

### 持ち物・特性・性格

詳細パネルから **持ち物**・**特性**・**性格** を設定します。
メガシンカが可能なポケモンは「メガシンカ」ボタンを押すことで、メガシンカ後のステータスや特性に瞬時に切り替わります。

### 技の選択

最大4つの技スロットをクリックして技ドロワーを開きます。
ドロワー内では各技の分類（物理・特殊・変化）、威力、命中率、タイプ、優先度などを確認しながら選択できます。

### 努力値の調整

「努力値」タブからスライダーまたは数値入力で努力値を配分します。

- **Champions ルール準拠**: 各能力値の上限は **32**、合計上限は **66** です。
- **リアルタイム検証**: 上限を超える配分は自動的に制限され、残り努力値がリアルタイムに表示されます。
- **耐久自動調整**: 「耐久調整」機能を利用すると、想定する仮想敵の攻撃を確実に耐える最適な配分を自動計算して反映できます。

## 戦略ノート

画面内の **「戦略ノート」** ワークスペースでは、チームの設計思想や立ち回りを3つの専用タブ（構築経緯・基本コンセプト・相手別メモ）に整理して自由に記録できます。

### 活用例

- **構築経緯**: なぜこの6体を採用したのか、誰を軸にした構築か。
- **基本選出プラン**: 「先発：カミ＋イーユイ」「後発：ウーラオス＋パオジアン」などの基本パターン。
- **相手パーティ別の対策**: トリル構築、雨パ、寿司構築など、主要アーキタイプに対する立ち回りの注意点。

戦略ノートはチームデータの一部として保存され、後述の変更履歴とも連動します。

## チーム変更履歴と復元

チームを調整していく中で、「前の配分や技構成に戻したい」「どこを変更したか確認したい」というケースに対応するため、**チーム変更履歴** 機能を搭載しています。

### 主な機能

- **バージョン自動保存**: ポケモンの入れ替えや努力値・技の変更を行うたびに、履歴としてバージョンが記録されます。
- **差分の視覚化**:
  - **セマンティック差分**: どのポケモンの努力値がどう変わったか、どの技が入れ替わったかを直感的なビジュアル差分で確認できます（デスクトップ環境で表示）。
  - **Pokepaste テキスト差分**: インポート/エクスポート形式のテキスト差分としても確認可能です。
- **モバイル最適化**: スマートフォン画面でも見やすいレイアウトに最適化された履歴ダイアログを提供しています。
- **ワンクリック復元**: 過去の任意のバージョンを選択し、「このバージョンを復元」をクリックするだけで、その時点のチーム構成に即座に戻すことができます。

## インポート / エクスポート

外部ツールとの連携や共有のための多彩な入出力機能を備えています。

| 操作                             | 説明                                                                        |
| :------------------------------- | :-------------------------------------------------------------------------- |
| **Pokepaste URL からインポート** | Pokepaste の URL を貼り付けるだけで、チーム構成を自動的に読み込みます。     |
| **テキストからインポート**       | Showdown / Pokepaste 形式のテキストを直接貼り付けてチームを一括登録します。 |
| **クリップボードにコピー**       | 現在のチーム構成を Pokepaste 互換テキストとしてワンクリックでコピーします。 |
| **Pokepaste を作成**             | チームを Pokepaste サイトに直接アップロードし、共有用リンクを発行します。   |

---

## 保存と共有

- **クラウド自動同期**: ログイン中はチームデータ、戦略ノート、変更履歴がすべて安全にクラウドへ自動同期されます。
- **ゲスト利用**: ログインしていない場合でも、ブラウザのローカルストレージに安全に一時保存されます。
- **共有リンクの発行**: 画面上部の **「チームを共有」** ボタンから、誰でも閲覧可能な専用URLを生成できます（努力値の公開/非公開を選択可能）。
