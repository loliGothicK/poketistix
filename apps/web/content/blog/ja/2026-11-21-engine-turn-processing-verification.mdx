Pokétistix で進めているバトルシミュレータ（`engine`）開発の一環として、『Pokémon Champions』環境における**ターン終了時の処理順**をあらためて網羅的に検証しました。

ダブルバトルでは、天候ダメージ・回復・定数ダメージ・場の終了・特性の発動が 1 ターンの終わりにまとめて発生するため、 **「どちらが先に処理されるか」** がそのまま勝敗に直結する場面が少なくありません。

この記事では、開発を通じて整理・検証した**ターン終了時処理の全体フロー**と、実戦で特に押さえておきたいポイントをプレイヤー向けにまとめます。

---

## 大前提：同じタイミングなら「すばやさ順」

ターン終了時の処理は決まった順番（フェーズ）に沿って進行します。同じ項目内で複数のポケモンが対象になる場合は、**場にいるポケモンのすばやさ順**（トリックルーム発動中は遅い順）に解決されます。

また、途中のダメージ処理などでひんしになったポケモンは、それ以降の処理対象から外れます。

---

## ターン終了時の全体処理順（検証結果）

『Pokémon Champions』環境で発生する主なターン終了時効果は、以下の順番で処理されます。

|   順   | カテゴリ                             | 主な効果・特性・もちもの                                                                                                        |
| :----: | :----------------------------------- | :------------------------------------------------------------------------------------------------------------------------------ |
| **1**  | **天候関連**                         | 天候の終了 → すなあらしダメージ → 天候特性（あめうけざら・かんそうはだ・サンパワー・アイスボディ）                              |
| **2**  | **遅延技**                           | みらいよち / はめつのねがい → ねがいごと                                                                                        |
| **3**  | **回復・状態回復ブロック**           | グラスフィールド回復 → たべのこし / くろいヘドロ → うるおいボディ → だっぴ → いやしのこころ                                     |
| **4**  | **継続回復・吸収**                   | アクアリング → ねをはる → やどりぎのタネ                                                                                        |
| **5**  | **定数ダメージ（状態異常・拘束）**   | どく / もうどく / ポイズンヒール → やけど → のろい → バインド                                                                   |
| **6**  | **定数ダメージ・能力変化（専用技）** | しおづけ → たこがため → あめまみれ（みずあめボム）                                                                              |
| **7**  | **状態変化の終了**                   | ちょうはつ → アンコール → かなしばり → でんじふゆう → テレキネシス → かいふくふうじ                                             |
| **8**  | **カウント系・ターン限定解除**       | ねむけ（あくび） → ほろびのうた → はねやすめ（ひこうタイプ復帰）・ひるみ解除                                                    |
| **9**  | **場の状態の終了**                   | 片側の場（おいかぜ等） → 全体の場（トリックルーム・じゅうりょく・マジックルーム・ワンダールーム・フィールド・フェアリーロック） |
| **10** | **終盤特性・技継続ブロック**         | さわぐの継続/終了 → ねむりによるあばれる中断 → はんすう・ムラっけ・かそく → しゅうかく → はらぺこスイッチ                       |

## 実戦で勝敗を分ける 2 つのポイント

一覧の中でも、ダブルバトルの実戦で特に勝敗へ直結しやすいのが次の 2 点です。

### 1. はねやすめとエレキフィールドの切れるタイミング

ターン終了時、**ねむけ（あくび）→ はねやすめ解除 → フィールド終了** の順で処理されます。

1. **ねむけ（あくび）** （8 番目）
2. **はねやすめ状態の終了（ひこうタイプ復帰）** （8 番目・ねむけの後）
3. **フィールド（エレキフィールド等）の終了** （9 番目）

この順番により、**エレキフィールドが切れる最終ターン**であっても、ねむけ判定の時点では**はねやすめによる接地状態もエレキフィールドもまだ両方残っています**。

したがって、あくびを受けたひこうタイプが「はねやすめ」を使ってターンを終えれば、エレキフィールドの恩恵を受けて**眠りを防ぐことができます**。はねやすめ解除やエレキフィールド終了はどちらもねむけ判定のあとに来るため、最終ターンでも安全に立ち回れるのがポイントです。

### 2. ほろびのうたのタイミング

**ほろびのうた**のカウント処理（8 番目）は、以下の 2 つの位置関係が実戦の勝敗を分けます。

- **トリックルーム終了より「先」に処理される**
  - ほろびのうたで互いの最後のポケモンが同時にカウント 0 になった場合、**すばやさ順（トリックルーム中は遅い順）に倒れ、最後に残った側の勝ち**になります。
  - ほろびのうた（8 番目）はトリックルーム終了（9 番目）より**先**に解決されるため、**トリックルームが切れる最終ターン**に同時カウント 0 となった場合は、まだトリックルームが有効な扱い（遅い順で倒れる＝**速い側が最後に残って勝ち**）になります。
- **すなあらし・どく・やけど・しおづけ等の定数ダメージより「後」に処理される**
  - 各種定数ダメージ（1〜6 番目）はすべてほろびのうた（8 番目）より先に計算されます。ほろび判定で勝てるすばやさ関係であっても、その手前の定数ダメージで倒れてしまえば先に負けが確定するため、最終ターンの残り HP 管理が重要になります。

## おわりに

ターン終了時の処理順は、1 つひとつの効果を知っていても「同時に重なったときにどちらが先か」を正確に把握しておくことで、詰め筋の読みや HP 管理の精度が大きく変わります。
