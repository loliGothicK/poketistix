## [ERROR] Bug Reports & Data Issues

<FeedbackCard
  title="Low Base Stats for Floette (Eternal Flower)"
  category="calculation"
  status="fixed"
  source="https://poketistix.mitama.io/ja/team-builder"
>
  <FeedbackMessage>
    [CALCULATION] フラエッテ(えいえんのはな)の種族値が低いようにみえます。かんちがいだったらすみません。ご確認よろしくお願いします。
    *(Floette Eternal Flower's base stats seem low. Please check if this is an issue.)*
  </FeedbackMessage>
  <FeedbackReply>
    Thank you for bringing this to our attention!

    Upon investigation, the base stats of standard Floette were erroneously referenced in the team builder and internal datasets.
    We have corrected the data to reflect Eternal Flower Floette's accurate base stats (`H74-A65-B67-C125-D128-S92`, BST 551).

  </FeedbackReply>
</FeedbackCard>

<FeedbackCard
  title="Match History Registration Fails or Data Disappears"
  category="error"
  status="fixed"
  source="https://poketistix.mitama.io/ja/battle-record"
>
  <FeedbackMessage>
    [ERROR] 対戦記録を登録後、データが一覧に反映されたと思ったらすぐにデータが消える。新規データを登録できない。
    *(After registering a match record, it appears in the list briefly and then disappears immediately. Cannot register new data.)*
  </FeedbackMessage>
  <FeedbackReply>
    We apologize for the inconvenience.

    A race condition occurred during match record synchronization where optimistic updates were prematurely rolled back under specific network conditions.
    We have revised the cache revalidation and local state reconciliation logic so that newly created entries reliably persist in the UI.

  </FeedbackReply>
</FeedbackCard>

<FeedbackCard
  title="Cannot Delete Season Records from Match History"
  category="error"
  status="fixed"
  source="https://poketistix.mitama.io/ja/battle-record"

  <FeedbackMessage>
    [ERROR] 対戦記録につきまして、作成したシーズン記録を削除する際、赤いゴミ箱のマークを押しても、反映されませんでした。ご確認いただけますと幸いです。
